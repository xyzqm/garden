## B. Non-Palindromic Substring

If $k < n$, we split into two cases:
- If $k$ is even, we discover that the string is only not $k$-good if every element is equal. Roughly, this is true because if the string begins with `abba`, in order for the next substring `bba?` to be a palindrome, b must equal `a`. Therefore, all adjacent characters must be equal to one another.
- If $k$ is odd, then the string must be something like "ababababab...ab". Similar reasoning as above.

We also have to account for the case when $k = n$ and the entire string is actually a palindrome: for this, I just copied Manacher's from GFG.
